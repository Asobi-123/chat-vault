# 云保险库 UI 收口 Workplan

状态：已完成。

## 目标与范围

把云保险库首页收为日常操作页，首屏优先显示连接状态、同步动作与远端聊天；把仓库池配置移入独立管理弹窗，消除“添加仓库”反复产生空白表单且无法撤销的体验问题。

本轮包含：

- 首页只保留状态、同步、刷新、仓库管理入口和远端聊天/备份浏览。
- 原生 `<dialog>` 仓库管理弹窗，兼容移动端 top layer。
- 添加仓库只在弹窗内编辑；取消不保存，不产生空白成员。
- 首仓使用“保存并连接”，新增仓库使用“添加并连接”；两者都复用现有的保存后连接流程。
- 默认令牌与仓库独立令牌字段都使用“访问令牌”命名；覆盖语义在辅助文字说明。
- 设备名、同步规则与说明默认折叠，不占云端操作首屏。
- 已保存仓库不增加删除能力；其范围归属不可安全地在本期移除。未保存草稿可随时取消。
- 首页提供明显的 `?` 帮助入口；说明内容不再藏在仓库管理弹窗底部。
- 仓库管理弹窗内的同步设置常显于仓库池上方；连接分支字段直接显示。
- 用户可见文案统一使用“附加仓库 / Additional Repository”，不再显示“成员仓库 / Member Repository”。
- 每次打开或切换到云保险库页都回到页面顶部，避免旧长表单留下的滚动位置遮住操作区。
- 主面板外层使用原生 `<dialog>` + `showModal()`，并按动态视口高度约束，避免半屏浏览器裁掉标题、Tab 和操作区。
- 面板、悬浮球和原生 dialog 不读取任何 SillyTavern `SmartTheme*` 颜色变量；全部使用 Chat Vault 自己的局部主题变量。
- 云保险库的刷新和说明按钮使用图标加文字，避免仅靠 tooltip 表达操作。
- checkbox、radio 和滚动条全部使用 Chat Vault 局部变量绘制，不接受浏览器或酒馆主题的原生颜色。
- 角色卡合并保留可辨识的 `.png` 文件名行；面板内 `code` 不继承酒馆的高亮背景。

## 已确认基线

- `feat/github-vault-pool` 已实现并手测多仓库同步、来源标识和失败隔离。
- 当前首页把首仓输入、成员表单、同步规则和五段说明放在同一个可滚动卡内，远端列表位于其后。
- “添加仓库”仅在 DOM 追加成员编辑器；无聚焦、无取消、无状态反馈。
- `/cloud/connect` 前端路径已先保存当前配置，再连接远端。
- 后端拒绝减少已保存成员，避免聊天范围 home 指向失效。

## 排除项

- 不修改仓库池的路由、同步、恢复、数据格式或成员删除规则。
- 不迁移、重均衡或删除任何已存在远端范围。
- 不更改已保存 token 的存储位置或返回安全边界。

## 执行顺序

1. `CVUI-01` 新增首页层级与仓库管理入口。
2. `CVUI-02` 实现原生仓库管理与添加/连接草稿流程。
3. `CVUI-03` 调整中英文文案、样式与移动端布局。
4. `CVUI-04` 运行自动回归、检查交互边界并更新手测文档。
5. `CVUI-05` 根据实测反馈调整帮助入口、弹窗层级、命名与滚动复位。
6. `CVUI-06` 将主面板改为原生 dialog，并补半屏视口约束。
7. `CVUI-07` 隔离全部面板主题变量并补齐云操作按钮文字。
8. `CVUI-08` 自绘原生控件、滚动条并清理角色卡合并文件名行。
9. `CVUI-09` 修正 checkbox 的酒馆主题残留，并恢复酒馆原有的勾选轮廓。

## 验收标准

- 已连接用户打开云保险库时，无需滚动即可看到同步入口、帮助入口与远端聊天/备份两栏的起始位置。
- 点击“添加仓库”只打开编辑弹窗；取消或关闭不会改变本地配置，也不会留下空白成员。
- 提交有效新 URL 后立即保存并连接；成功后显示成员已连接，失败后保留表单和可读错误。
- “访问令牌”不再以“成员令牌”作为用户可见名称；独立凭据仍明确为可选覆盖。
- 单仓用户仍可保存、连接、同步、刷新、浏览和恢复。
- 原有仓库池自动测试、分块测试、语法检查和 `git diff --check` 通过。
- 进入云保险库页不会继承旧长表单的滚动位置。
- 半屏浏览器下，主面板标题、Tab 和当前页操作区不会被视口顶部裁掉。
- `extension/` 的 UI 代码不再引用 `SmartTheme*` 颜色变量，也不存在 `color: inherit` 作为 Chat Vault 面板文字回退。
- checkbox、radio、滚动条和角色卡合并的代码样式均不受酒馆原生控件或 `code` 样式影响；文件名可见且无高亮底。
